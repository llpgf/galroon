# Galroon 0.2.0

## 繁體中文

Galroon 0.2.0，API 1、收藏資料庫 schema 54。從 0.1.0 升級時直接安裝或更新容器即可，資料庫會自動升級；升級前建議先在「設定 → 備份與還原」匯出一份備份。

### 新功能與改進

- **收藏排序、記憶與無限捲動**：修正依發售日排序只比對年份的問題（改為完整 `YYYY-MM-DD` 正規化比較），記住收藏排序與每頁筆數設定，新增每頁 60／100／150／200 部與無限捲動模式。
- **作品詳細頁改版與快速開啟資料夾**：Hero 區新增一鍵開啟資料夾（本機桌面直接開啟，遠端 NAS 桌面支援每來源一次設定本機／SMB 對應路徑，網頁版提供複製路徑）、內嵌個人評分、前 5 個標籤預覽、可點擊發售日與修正中日文簡介折疊；角色區新增主角／配角篩選與收合；檔案列表置頂並重整筆記與 VNDB／Bangumi 同步卡片。
- **全新 Glass 圖示**：更新應用圖示、網頁 favicon、桌面版圖示與側邊欄左上角標誌。
- **LLM 簡介與角色批次翻譯**：支援 OpenAI、Gemini 與 Claude 翻譯作品簡介與角色資料，並提供保留日文原名切換。
- **內建排程備份與首次啟動還原**：新增可攜／完整備份模式、排程備份背景服務與設定介面、首次啟動還原精靈與 NAS `/backups` 掛載。
- **首頁、發售日曆與統計**：新增發售日曆、收藏統計頁、可拖曳重排的遊玩狀態看板、無狀態預設值與加入日期／上市日期排序。
- **區網瀏覽器與配對強化**：支援擁有者密碼登入瀏覽器直接編輯（含區網）、區網管理介面、桌面配對工作階段長效保持與 MCP 區網 Core 支援。
- **配對與監看穩定度**：支援 DLsite 作品編號查詢、改善 Bangumi 配對與 VNDB 補配、修正 VNDB 搜尋鎖競爭、補上每 60 秒頂層資料夾防漏掃描，以及修復設定頁核取方塊排版。

## English

Galroon 0.2.0, API 1, catalog schema 54. Upgrading from 0.1.0 migrates the catalog automatically; export a backup in Settings → Backup & restore before upgrading.

### What's new

- **Collection sorting, persistence, and infinite scroll**: Fixed release-date sorting to compare full normalized dates (`YYYY-MM-DD`) instead of year only, persisted sort and page-size choices, and added 60 / 100 / 150 / 200 per-page options plus infinite scroll.
- **Redesigned Work Detail & quick Open Folder**: Added one-click Open Folder (direct on local desktop, per-source local/SMB path mapping for remote NAS desktop, and Copy Path on web), inline Hero personal rating, Hero tag previews, clickable release dates, accurate CJK description overflow detection, character role filters and collapse, files-first section ordering, and Glass cards for Notes and VNDB/Bangumi sync.
- **New Glass icon**: Updated app icon, favicon, desktop icons, and sidebar wordmark emblem.
- **LLM description & batch character translation**: OpenAI, Gemini, and Claude support with an option to keep original Japanese character names.
- **Built-in backup schedule & first-run restore**: Portable and full backup modes, scheduled backup worker and UI, first-run restore wizard, and NAS `/backups` mount.
- **Home, release calendar & statistics**: Added release calendar, statistics view, reorderable play-status board, no-status default, and date-added / release-date sorting.
- **LAN & pairing improvements**: Owner-password browser editing over LAN, LAN management UI, persistent paired desktop sessions, and MCP LAN Core support.
- **Matching & watch reliability**: DLsite product-code title lookup, improved Bangumi/VNDB pairing, VNDB search lock-contention fix, 60-second top-level watch safety sweep, and settings checkbox layout fix.
