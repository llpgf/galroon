# Galroon 0.3.0

## 繁體中文

Galroon 0.3.0，API 1、收藏資料庫 schema 54。本版本為內置簽章更新基準版：完成本次 NAS 容器部署（`scripts/nas/deploy.sh`）與 Windows 桌面版安裝後，未來版本即可直接在 Galroon 介面內一鍵同時更新 NAS Core 與 Windows 桌面版。

### 新功能與改進

- **Roon 式內置簽章協同更新**：支援在更新橫幅或「設定 → 關於」一鍵依序更新 NAS Docker Core（含 Web UI）與 Windows 桌面版，並即時顯示各階段下載、驗簽與重啟進度。
- **單一 Minisign（Ed25519）簽章驗證**：Windows 安裝包與 NAS 更新包共用同一組 Ed25519 簽章金鑰；Core 端會依序驗證官方來源、SHA-256、Ed25519 簽章與版本單調遞增（防降級），並阻擋壓縮包路徑穿越與符號連結。
- **NAS 容器自動回滾啟動器**：新增非 root `docker/entrypoint.sh` 啟動器，透過優雅關閉（暫停背景任務 + SQLite WAL checkpoint + 退出碼 `42`）無縫切換至 `/data/runtime/releases/<version>/`；若新版尚未進入健康狀態即異常退出，會自動回滾回上一個健康版本並回報錯誤。
- **Windows 桌面版內置更新（Tauri Updater）**：整合 `tauri-plugin-updater` 與 `tauri-plugin-process`；本機 Windows 模式會先下載完安裝包再優雅停止本機 `galroon-core.exe` 釋放鎖檔，隨後被動安裝並自動重啟。
- **自動化簽章發佈流程**：新增統一 GitHub Actions Release workflow，於 `v*` tag 自動編譯、簽章、驗簽並上傳 Windows 安裝包、`latest.json`、NAS 更新包、`nas-latest.json` 與 `SHA256SUMS.txt`。

## English

Galroon 0.3.0, API 1, catalog schema 54. This is the baseline release enabling built-in signed updates: after deploying this container image once via `scripts/nas/deploy.sh` and installing this Windows desktop build, future releases can update both NAS Core and Windows Desktop in one click directly inside Galroon.

### What's new

- **Roon-style built-in coordinated updates**: Update NAS Docker Core (including its bundled Web UI) and Windows Desktop in one click from the update banner or Settings → About, with live progress for download, signature verification, staging, and restart health checks.
- **Unified Minisign (Ed25519) signing**: Windows installers and NAS update bundles share a single Ed25519 signing keypair; Core enforces trusted release origins, SHA-256 checksums, Ed25519 signature verification, strict SemVer monotonicity, and safe archive extraction (blocking symlinks and path traversal).
- **NAS launcher with automatic rollback**: Added non-root `docker/entrypoint.sh` supervision with graceful exit-code `42` restarts after job pause and SQLite WAL checkpoint; startup failures before health confirmation roll back automatically to the previous healthy release.
- **Windows Desktop in-app updater**: Integrated `tauri-plugin-updater` and `tauri-plugin-process`; local Windows mode downloads the signed installer first, cleanly stops local `galroon-core.exe` until `core.lock` is released, then applies the passive update and relaunches.
- **Signed Release automation**: Added a unified GitHub Actions Release workflow that builds, signs, cross-verifies against the embedded public key, and publishes Windows installers, `latest.json`, NAS bundles, `nas-latest.json`, and `SHA256SUMS.txt`.
