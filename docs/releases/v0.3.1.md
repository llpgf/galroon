# Galroon 0.3.1

## 繁體中文

Galroon 0.3.1，API 1、收藏資料庫 schema 54。本修訂版用於端到端驗證 Roon 式內置簽章更新（從 `0.3.0` 一鍵同時自動更新 NAS Docker Core 與 Windows 桌面版）。

### 變更摘要

- **端到端自動更新驗證版**：由 GitHub Actions 以統一 Minisign（Ed25519）金鑰簽署並發佈 `latest.json`、`nas-latest.json`、Windows 安裝包與 NAS 更新包，供 `0.3.0` 直接於介面內一鍵升級測試。

## English

Galroon 0.3.1, API 1, catalog schema 54. Maintenance patch release for end-to-end verification of Roon-style built-in signed updates from `0.3.0` across NAS Docker Core and Windows Desktop.

### Summary

- **End-to-end auto-update verification release**: Signed with the unified Minisign (Ed25519) keypair and published with `latest.json`, `nas-latest.json`, Windows installer, and NAS update bundle for in-app upgrades from `0.3.0`.
