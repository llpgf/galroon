# Galroon 0.4.0

## 繁體中文

Galroon 0.4.0，API 1、收藏資料庫 schema 54。從 0.3.x 升級可直接於介面內一鍵同時更新 NAS Core 與 Windows 桌面版。

### 新功能與改進

- **Roon 式三頁籤作品編輯器**：重設「編輯資料」為三頁籤視窗（辨識與來源／詮釋資料偏好設定／編輯作品），可逐欄設定偏好 **VNDB**、**Bangumi**、**DLsite** 或**自訂編輯**，所選來源缺值時自動回退其他可用來源，並支援一鍵複製來源文字與「還原編輯…」。
- **DLsite 封面與完整中繼資料**：支援以 `RJ`/`VJ` 編號抓取 DLsite 官方主圖封面（`img.dlsite.jp`）、社團、發售日、簡介與標籤，並自動偵測作品與檔案路徑內的 DLsite 編號。
- **Bangumi 封面補齊與公開抓取**：綁定 Bangumi 條目時自動快取並補齊空白封面；即使未登入個人 token 也可使用公開 API 抓取非限制級條目（已設定 token 則同步支援限制級條目）。
- **本機自訂封面持久上傳**：新增 `POST /api/works/{id}/cover`，支援直接上傳 PNG／JPEG／WebP 圖片作為作品封面，永久存於 `artwork-library.sqlite`（`local://artwork/<sha256>.<ext>`），不受快取清理影響且納入完整備份。
- **內置更新器介面與體驗強化**：改以高對比琥珀／紅色警示卡與完整繁中說明呈現背景任務阻擋與失敗訊息；遇背景任務擋下時主按鈕直接切換為「暫停進行中任務並更新」，並在更新過程中以藍色進度卡與持續保留的 `步驟 1/2` / `步驟 2/2` 標記清楚呈現每個階段。

## English

Galroon 0.4.0, API 1, catalog schema 54. Users on 0.3.x can upgrade both NAS Core and Windows Desktop in one click directly inside Galroon.

### What's new

- **Roon-style 3-tab Metadata Editor**: Redesigned Edit Metadata into **Identify & sources**, **Metadata preferences**, and **Edit work**, letting you choose per-field source preferences across **VNDB**, **Bangumi**, **DLsite**, or **Edit (custom)** with automatic fallback, one-click copy from source, and **Revert edits…**.
- **DLsite covers and full metadata**: Fetch official DLsite main cover art (`img.dlsite.jp`), studio, release date, summary, and tags by `RJ`/`VJ` code, with automatic code detection from descriptions, titles, and bound resource paths.
- **Bangumi cover backfill & public fetch**: Linking a Bangumi subject now caches subject metadata and backfills empty covers automatically; public Bangumi subject fetch works even without a personal token (using the saved token when connected).
- **Permanent custom local cover upload**: Added `POST /api/works/{id}/cover` for uploading PNG/JPEG/WebP artwork stored permanently in `artwork-library.sqlite` (`local://artwork/<sha256>.<ext>`), surviving cache clears and included in full backups.
- **Built-in updater UX improvements**: Added high-contrast amber/red alert callouts with localized active-task explanations, automatic promotion of the primary CTA to **Pause active tasks and update** when blocked by background jobs, and a persistent `Step 1/2` / `Step 2/2` progress card with spinner feedback.
