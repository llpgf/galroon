# Galroon 0.1.0

## 繁體中文

Galroon 第一個正式版本（Windows x64），API 1、收藏資料庫 schema 50。自 v0.0.2 預發佈版以來合併了 60 多個 PR。

### 下載與安裝

下載 Assets 中的 **Galroon_0.1.0_x64-setup.exe** 並執行。需要 WebView2；安裝包未簽署，Windows 可能顯示 SmartScreen 提示。`SHA256SUMS.txt` 提供所有檔案的 SHA-256：

```powershell
Get-FileHash .\Galroon_0.1.0_x64-setup.exe -Algorithm SHA256
```

從 0.0.2 升級時直接安裝即可，收藏資料庫會自動升級到 schema 50；升級後無法再用舊版開啟。建議先在「設定 → 備份」匯出一份備份。

### 新功能與改進

- **匹配更準確**：匹配演算法第 15 版。特典、OST、破解等成員會歸入正確作品卡；合集可綁到所含的每部作品；重製版有自己的卡；頂層只有特典的資料夾標示為「只有特典」。原則不變：寧可留待處理，也不錯配。
- **AI 協助配對（僅建議）**：透過 MCP 提出配對建議，必須由你在「整理」中確認才會套用。
- **VNDB 與 Bangumi 雙向同步**：遊玩狀態與個人評分可與你的 VNDB、Bangumi 帳號雙向同步。
- **全新介面**：Glass 介面、bento 首頁（遊玩狀態分頁／看板）、繁體中文介面、搜尋時平假名與片假名視為相同。
- **封面離線保存**：封面快取可保存最大 16 MiB 的圖片，收藏變動時封面不再重新載入。
- **NAS／區網 Core（第一階段）**：Core 可在 Linux（Synology NAS 的 Docker）上無介面執行，收藏以唯讀方式掛入；桌面版可用配對字串連線到區網 Core。另有 NAS 資料的自動備份與還原腳本。
- **新版提醒**：Core 每天檢查 GitHub 的正式版本，有新版時所有連線的程式都會提示；可在「設定 → 關於」關閉。

### 驗證範圍

本版安裝包在發佈前通過 Mac 端到端驗收（真實 VNDB、38 個資料夾的 NAS 測試集、錯配 0）與 Windows 安裝驗收（US-4.1），並以真實收藏的匹配重放確認錯配為 0。各項數字與日期見 GitHub Release 頁面。

### 已知限制

- 安裝包未簽署。
- 尚未在全新未使用過的 Windows 及最低系統規格上測試。
- 區網 Core 為第一階段：配對憑證只支援 Windows 桌面版；瀏覽器與其他平台的用戶端尚未完成。
- macOS 桌面版尚未提供。

資料庫、遊戲資料、登入憑證與本機測試產物不包含在此 Release。

## English

The first full release of Galroon (Windows x64), API 1, catalog schema 50. More than 60 pull requests have been merged since the v0.0.2 pre-release.

### Download and install

Download **Galroon_0.1.0_x64-setup.exe** from the Assets below and run it. WebView2 is required. The installer is not code-signed, so Windows may show a SmartScreen prompt. `SHA256SUMS.txt` lists the SHA-256 of every file:

```powershell
Get-FileHash .\Galroon_0.1.0_x64-setup.exe -Algorithm SHA256
```

To upgrade from 0.0.2, just install. The catalog is upgraded to schema 50 automatically, and older versions can no longer open it afterwards. Export a backup first in Settings → Backup.

### What's new

- **More accurate matching**: matching algorithm 15.
  - Bonus, OST and crack members are filed into the right work card.
  - A compilation is bound to every work it contains.
  - Remakes get their own card.
  - Top-level folders that hold only bonus material are marked bonus-only.
  - The rule is unchanged: leave a resource for review rather than mis-match it.
- **AI-assisted matching (suggestions only)**: match suggestions arrive through MCP and apply only after you confirm them in Organize.
- **Two-way VNDB and Bangumi sync**: play status and personal rating sync both ways with your VNDB and Bangumi accounts.
- **New interface**: Glass UI, a bento home page (play status tabs and board), Traditional Chinese UI, and search that treats hiragana and katakana alike.
- **Offline covers**: the artwork cache keeps images up to 16 MiB, and covers no longer reload when the collection changes.
- **NAS / LAN Core (phase 1)**: Core runs headless on Linux (Docker on a Synology NAS) with the library mounted read-only. The desktop app can connect to a LAN Core with a pairing string. Scripts for automatic NAS data backups and restores are included.
- **Release notices**: Core checks GitHub daily for full releases, and every connected client shows a notice when one is out. Turn it off in Settings → About.

### Validation

Before release, this installer passed the macOS end-to-end acceptance (live VNDB, 38-folder NAS test set, 0 false matches) and the Windows installer acceptance (US-4.1), and a matching replay on a real collection confirmed 0 false matches. Numbers and dates are on the GitHub release page.

### Known limitations

- The installer is not code-signed.
- Not yet tested on a clean, never-used Windows machine or on the minimum supported system.
- The LAN Core is phase 1: pairing credentials work only in the Windows desktop app; browser and other platform clients are not finished.
- There is no macOS desktop app yet.

Databases, game data, credentials and local test artifacts are not part of this release.
